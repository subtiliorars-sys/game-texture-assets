# TEXTURE GO-BIG

Local vendor ~12.5+ GB of CC0 maps (2026-07-13: **1940** ambientCG + **780** Poly Haven @ 1K).

Catalog ID lists: `catalog/ambientcg-ids.txt`, `catalog/polyhaven-ids.txt`. Binaries stay gitignored under `vendor/`.

GitHub may host this as **Release zip batches** (see Releases) if git clone of the full binary tree is too heavy.
Re-fetch anytime with `scripts/fetch-*-parallel.ps1`.
